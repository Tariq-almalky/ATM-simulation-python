# Python ATM Simulation

A simple ATM system built with Python as a command-line application.  
The program simulates basic banking operations such as logging in with a username and PIN, checking balance, withdrawing and depositing money, and viewing transaction history.

## Features
- User authentication with username and PIN
- Check account balance
- Withdraw and deposit money
- Transaction history tracking
- Input validation and error handling

## Technologies
- Python
- Object-Oriented Programming (OOP)
- Command Line Interface (CLI)

## Purpose
This project was created to practice Python fundamentals, functions, classes, and basic program logic.
